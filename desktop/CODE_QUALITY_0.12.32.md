# 0.12.32 桌面端修复记录

本轮针对输入冲突、异步状态、文件与配置可靠性清理桌面客户端；手机模块未修改。

| 问题 | 修复 |
| --- | --- |
| 鼠标模式左右键落入绑定，覆盖组件截获直接触摸 | 页面与引擎同时隔离模式；左键始终按坐标触摸，右键/中键不触发绑定，无可用 slot 时给出提示 |
| 隐藏光标位置命中其它组件 | 视角模式直接走鼠标绑定，跳过画布控件命中 |
| 按住鼠标切换模式后触发新动作 | 清除旧手势并抑制到真实松开，新一次按下才生效 |
| Hook 与 XAML 双重投递、Esc 自动重复 | 操控输入只走原生入口，编辑/预览保留 XAML；重复按下去重，Esc 两次独立按下分别退视角和停止 |
| 全局 Tab 捕获拦截系统切换 | Alt/Windows 修饰键保留系统投递；组合 Tab 不触发视角切换，先清理当前输入，再交给系统。此分支尚未做交互桌面实点验证 |
| DOWN/UP 在一次采样间到达而丢失短按 | 保留输入边沿，每次采样消费每个输入的一个边沿，有界队列防止传输停顿造成无限积压 |
| 失焦后键盘、切换型按钮和触点残留 | 禁用输入、清理按键与控件状态并在采样边界释放全部触点，恢复时不重放旧手势 |
| 多个观察组件互相覆盖 | 聚合所有观察组件的按住状态，最后一个松开才退出 |
| 滑动时长无效、长按组件的连发模式无效 | 按单调时钟执行滑动和连发，按实际持有触点计算占用数量 |
| 鼠标移动队列无界增长 | 相邻 MOVE 入队时合并，保留 DOWN/UP 顺序和最终有效坐标 |
| 运行配置引用界面可变对象、取消后仍显示运行 | 启动前克隆与校验，采样线程退出时释放触点、输入通道和计时器，更新停止状态；引擎释放时销毁 UDP 资源 |
| 页面初始化未完成就能尝试开始 | 明确页面就绪状态；初始化、重连期间禁用开始按钮，拒绝提前启动 |
| 快速切页时旧任务释放新页面、迟到设备/屏幕结果覆盖当前状态 | 分离同步离开与异步清理；等待旧清理，使用导航/环境/连接代次检查，延迟 Unloaded 不清理已返回的页面 |
| 每条活动日志都重新读设备信息 | 仅连接状态或连接代次变化时重新初始化；读取设备/屏幕使用独立、有超时的通道 |
| 光标更新占用主通道、慢连接堆积请求 | 独立光标连接，合并到最新状态，超时取消；停止时撤销旧连接并有界清理 |
| 关闭窗口直接销毁连接，未等触点抬起 | 关闭流程先等待页面、引擎、捕获与观察任务释放，再销毁主连接和窗口 |
| 编辑器重叠命中底层，非正方形画布命中圆变形 | 按绘制层级逆序命中，按钮按实际像素圆计算；视角覆盖轮盘时优先命中视角 |
| 文件列表迟到覆盖新目录，选择文件后目录变化导致传错路径 | 目录请求带版本；上传/下载在文件对话框前固定路径与设备连接代次；使用独立通道和工作计数 |
| 配置直写、一个坏布局丢弃全部布局、显式点击类型被迁移成开火 | 同目录临时写入并替换；逐份恢复有效布局并备份原文件；仅迁移缺失的旧字段 |
| 重复 ID、负 slot、NaN、未知类型和模式按键冲突 | 校验并明确报错，失败不覆盖有效配置 |
| 输入和平台钩子混在巨型页面文件，日志阻塞输入 | 拆为 `GamepadPage.Input.cs` / `GamepadPage.NativeInput.cs`，移除重复与失效分支；日志有界后台写入并轮换 |

主要源文件：`GamepadEngine.cs`、`SampledInputState.cs`、`GamepadPage*.cs`、`MainWindow.xaml.cs`、
`FilesPage.xaml.cs`、`GamepadProfile*.cs`、`AtomicFile.cs`、`BufferedLog.cs`、`SettingsStore.cs`。
